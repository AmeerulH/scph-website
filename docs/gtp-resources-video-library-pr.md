# feat(gtp): add Resources and a video library

GTP visitors need a permanent place to download conference documents and browse a growing video archive. Add Resources to the main navigation with grouped toolkit downloads and expandable report entries. Add Media → Videos with four daily highlights, a searchable day-filtered recordings archive, and a curated playlist.

Editors manage PDF attachments and individual videos in Sanity. Files can become available independently; pending documents/highlights stay clearly labelled. The existing published videos stay visible until a reviewed, revision-guarded migration atomically enables the individual library. Source content, image references and ordering are preserved, and old entries never reappear after unpublishing.

Collections use the existing floating Media pill selector with active scroll tracking and mobile horizontal scrolling. The native day dropdown has reserved chevron spacing, and the collection label is Session Recordings. Player opening/closing uses brief, interruptible fade/scale transitions and controls provide press feedback. Keyboard actions remain immediate; reduced-motion preferences remove scaling while retaining a gentle player fade. Playback stops before the closing transition completes and focus returns to the selected video.

Validation: behavioural, responsive browser and targeted motion checks passed, including a 200-session archive, migration/URL/download boundaries, player interruption/focus, keyboard/reduced motion, floating selectors, chevron spacing and filter/pagination/Back behaviour. App and Studio type checks passed; final production build passed. Full lint matches the original baseline exactly: 17 existing errors and 11 warnings. The original 30-route mobile scan, subsequent motion checks and selector recheck are recorded in docs/gtp-library-validation.md: Resources 86; latest three-sample medians Media 81 / Videos 81. The earlier Media 78 single sample and 80 confirmation are retained. Four other routes in the full scan were below 80. The original independent source/security, visual and player-motion reviews have no outstanding findings; subsequent selector corrections passed the expanded browser suite and scoped detector. Physical held-touch feel and real playback remain manual content/device checks.

Release work is separate: schema/Studio deployment, production shell seeds, migration, file uploads and publishing have not been performed. Both seeds and the migration were exercised in dry-run mode only. Test real new PDFs and YouTube playback when approved content is available. See docs/gtp-resources-video-library.md for editor instructions and rollout commands.

Team review does not require CMS writes. On Vercel Preview, `/dev/gtp-library-review?view=resources&case=partial` shows the populated Resources sample; `/dev/gtp-library-review` shows Videos and `?case=many` shows 200 synthetic recordings. All samples are labelled/noindex and remain inaccessible on production. Public routes continue to show published CMS content, including the two preserved legacy videos. Production CMS/schema/Studio changes and merge/release are separate from this PR.
